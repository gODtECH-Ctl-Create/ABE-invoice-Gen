# ABE Invoice & Projects

A lightweight invoice generator and project tracker for freelancers, agencies, consultants, and small businesses.

## Product scope

- Invoices: create, edit, save, preview, print/save as PDF, and prepare email messages.
- Projects: track clients, status, progress, budget, deadlines, and notes.
- Company branding: company name, logo, address, contact details, bank details, accent colors, and watermark text.
- Default visual theme: based on the ABE TechLab invoice design, but fully customizable for each business.

The first release is local-first: data is stored in the user's browser so the app works immediately without exposing a shared database. A future cloud mode can add Supabase authentication and synchronized storage.
